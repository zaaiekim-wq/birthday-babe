KADO DIGITAL — BLUE EDITION (CLICK FLOW)

ALUR INTERAKSI:
1. Loading screen dengan bunga melayang.
2. Amplop biru yang bisa diketuk untuk dibuka.
3. Halaman Happy Birthday.
4. Tombol OPEN YOUR LETTER membuka surat.
5. Tombol OUR LITTLE MEMORIES membuka kolase foto.
6. Halaman penutup; tombol replay kembali ke amplop.

Bagian antar halaman tidak memakai scroll panjang; pindah layar dengan tombol klik. Di layar kecil, surat mungkin perlu scroll sedikit untuk membaca seluruh isi.

PERSONALISASI:
Edit CONFIG pada script.js: name, date, letterDate, letter, ps.

FOTO:
Ganti file assets/photos/foto-1.jpg, foto-2.jpg, foto-3.jpg dengan foto sendiri (nama file sama).

MUSIK:
Taruh MP3 pilihan di assets/music/lagu-kamu.mp3. Browser baru mengizinkan musik setelah interaksi pengguna, jadi musik dicoba mulai setelah amplop diketuk.

Preview: buka folder di VS Code/Trae dan jalankan index.html menggunakan Live Server.
